# ADR Template

Use as `requirements/<FeatureName>/decisions/ADR-<NNN>.md`.

```markdown
# ADR-XXX: <Decision Title>

**Status**: Proposed | Accepted | Deprecated | Superseded
**Date**: YYYY-MM-DD
**Deciders**: <Names / roles>
**Discovery source**: <which OQ this resolves, e.g., TF-01>

## Context
Why did this decision need to be made? What forces were in tension?

## Options Considered
What were the realistic alternatives? Reference the OQ option table if applicable.

## Decision
What was chosen?

## Rationale
Why was this the right call? What convinced the deciders?

## Consequences
What does this enable? What does it foreclose? What new questions does it raise?
```
